🌐 Versão Web — GitHub Pages
O Mlks da Vila também possui uma versão web desenvolvida com HTML, CSS e JavaScript, permitindo acessar suas principais funcionalidades diretamente pelo navegador.
Acesse o projeto: https://bellycastrom.github.io/Mlks-da-vila-/
🎯 Objetivo do projeto
O Mlks da Vila é um sistema comunitário desenvolvido para apoiar a organização das atividades educacionais e sociais de uma ONG localizada em São Bernardo do Campo, São Paulo.
O projeto está alinhado ao ODS 4 — Educação de Qualidade, contribuindo para a organização das ações comunitárias, o acompanhamento da participação dos alunos e o gerenciamento dos recursos educacionais.
⚙️ Funcionalidades
Cadastro e gerenciamento de participantes.
Cadastro de atividades educacionais.
Registro individual de presenças e ausências.
Contagem automática de participantes presentes.
Visualização dos resultados das atividades.
Cadastro e consulta de livros.
Controle de empréstimos e devoluções.
Interface responsiva para computadores e dispositivos móveis.

Hospedagem da interface web🏗️ Arquitetura
O projeto possui duas modalidades de execução:
Versão local: executa o servidor Python e utiliza SQLite para armazenar atividades, participantes e registros da biblioteca.
Versão GitHub Pages: executa HTML, CSS e JavaScript diretamente no navegador, utilizando armazenamento local para manter os dados no dispositivo.
Na versão GitHub Pages, os registros não são sincronizados entre diferentes dispositivos e navegadores. Essa modalidade é destinada à demonstração acadêmica e não substitui um banco de dados centralizado.
🚀 Publicação
A versão estática pode ser publicada gratuitamente pelo GitHub Pages.
Disponibilizar o arquivo index.html na raiz do repositório.
Manter os arquivos CSS e JavaScript referenciados pela página.
Acessar Settings → Pages no GitHub.
Selecionar a branch main e a pasta /(root).
Acessar o endereço público após a publicação.
♿ Acessibilidade
A interface utiliza contraste adequado, menus identificados, campos com rótulos, indicadores textuais de presença e ausência e navegação adaptada para dispositivos móveis.
📌 Limitações e melhorias futuras
A solução ainda não possui autenticação de usuários nem sincronização de dados entre dispositivos na versão estática.
Como evolução futura, estão previstos o uso de banco de dados centralizado, controle de acesso dos voluntários e relatórios consolidados de participação.
